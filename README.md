# PRODIGY_WD_01 — Responsive Landing Page

A responsive landing page for **Fieldnote**, a fictional weekly-planning product. The fixed navigation changes appearance on scroll and hover; on small screens it becomes an accessible toggle menu.

## Run

Open `index.html` in a browser. No build step or package install is needed. Google Fonts are loaded from the web; system sans-serif fallbacks are included.

## Features

- Fixed navigation with scroll state, hover feedback and mobile menu
- Responsive hero, feature sections, quote and sign-up form
- Keyboard skip link, semantic landmarks, visible focus and live form feedback
- CSS illustrations, so the project has no external image dependencies

The preview form is a front-end demonstration and does not submit email addresses to a service.
